📝 Où regarder les logs?

  • Console de l'IDE (IntelliJ): Onglet "Services" ou "Run"
  • Terminal où Maven s'exécute: Cherchez les lignes avec "🔍" ou "👤"
  • Fichier de logs: S'il existe, regardez dans logs/ ou target/logs/
