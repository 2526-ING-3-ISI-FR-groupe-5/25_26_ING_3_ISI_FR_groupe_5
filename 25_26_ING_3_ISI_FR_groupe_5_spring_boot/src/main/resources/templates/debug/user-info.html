📚 Instructions pour Résoudre les Problèmes

Si vous avez un 403 sur /admin/inscriptions ou /admin/migration:

  1. Vérifiez ci-dessus que hasRole('SUPER_ADMIN') ou hasRole('ADMIN_INSTITUT') est OUI
  2. Si NON, il faut assigner le rôle en base de données (voir ci-dessous)
  3. Si OUI mais vous avez quand même un 403, effacez les cookies et reconnectez-vous

Pour modifier les rôles en PostgreSQL:

-- Assigner SUPER_ADMIN à un utilisateur
INSERT INTO utilisateurs_role (utilisateur_id, role_id)
SELECT u.id, r.id FROM utilisateur u, role r
WHERE u.email = 'votre.email@example.com'
  AND r.nom = 'SUPER_ADMIN'
  AND NOT EXISTS (
    SELECT 1 FROM utilisateurs_role ur
    WHERE ur.utilisateur_id = u.id AND ur.role_id = r.id
  );

-- Ou assigner ADMIN_INSTITUT
INSERT INTO utilisateurs_role (utilisateur_id, role_id)
SELECT u.id, r.id FROM utilisateur u, role r
WHERE u.email = 'votre.email@example.com'
  AND r.nom = 'ADMIN_INSTITUT'
  AND NOT EXISTS (
    SELECT 1 FROM utilisateurs_role ur
    WHERE ur.utilisateur_id = u.id AND ur.role_id = r.id
  );
